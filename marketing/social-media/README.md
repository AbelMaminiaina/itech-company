# Programme Marketing Social Media - 30 Jours

## Vue d'ensemble

Ce dossier contient le programme complet de publication sur les réseaux sociaux pour iTech-Company pendant 30 jours.

## Structure des fichiers

```
marketing/social-media/
├── README.md                    ← Ce fichier
├── calendrier-30-jours.json     ← Calendrier JSON (pour scripts)
├── facebook/
│   └── posts-30-jours.md        ← 30 posts Facebook détaillés
├── linkedin/
│   └── posts-30-jours.md        ← 30 posts LinkedIn détaillés
├── tiktok/
│   └── videos-30-jours.md       ← 30 idées vidéos TikTok
├── assets/
│   └── guide-visuels.md         ← Guide création visuels
└── scripts/
    └── automatisation.md        ← Guide automatisation
```

## Résumé du Programme

| Plateforme | Posts/Jour | Ton | Format principal |
|------------|------------|-----|------------------|
| Facebook | 1 | Engageant, accessible | Carrousels, Vidéos |
| LinkedIn | 1 | Professionnel, B2B | Articles, Carrousels PDF |
| TikTok | 1 | Fun, tendance | Vidéos courtes 15-60s |

## Calendrier par Semaine

### Semaine 1: Présentation
- Qui sommes-nous
- Nos services
- L'équipe
- Témoignages
- Valeurs

### Semaine 2: Expertise
- Focus Développement Web
- Focus Mobile
- Focus UI/UX
- Focus DevOps
- Focus IA

### Semaine 3: Éducation
- Tips et erreurs à éviter
- Guides pratiques
- Conseils SEO/Sécurité
- Behind the scenes

### Semaine 4: Conversion
- Offre spéciale
- Portfolio showcase
- FAQ
- Témoignages vidéo
- Bilan et remerciements

## Outils d'Automatisation

### Gratuit
- **Meta Business Suite** - Facebook/Instagram
- **Buffer (gratuit)** - 3 comptes, limité

### Payant (Recommandé)
- **Publer** (~12€/mois) - Tous réseaux dont TikTok
- **Buffer Pro** (~15€/mois) - Plus de fonctionnalités

## Actions Requises

### 1. Créer les visuels
Voir `assets/guide-visuels.md` pour:
- Dimensions par plateforme
- Charte graphique
- Liste des visuels à créer
- Outils recommandés

### 2. Configurer l'automatisation
Voir `scripts/automatisation.md` pour:
- Configuration des outils
- Workflow hebdomadaire
- Templates réutilisables

### 3. Planifier les publications
1. Créer les visuels dans Canva
2. Rédiger les textes (fournis dans les fichiers)
3. Planifier via Meta Business Suite / Publer
4. Configurer les rappels pour TikTok
